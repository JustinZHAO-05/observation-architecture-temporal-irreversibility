# Observation architecture and the identifiability of temporal irreversibility

Research code and numerical results for the manuscript by **Yanzhe Zhao**  
School of Future Technology, Tianjin University  
Contact: justinzhaoyz@outlook.com

This paper develops Gaussian observational-equivalence theorems for temporal irreversibility, a one-sample-delay reversible-latent construction, spectral-power optimization, filter-invariant cycle lower bounds, confidence-calibrated inference, and an EEG illustration.

## Reproducibility material

The complete public research-file release is prepared separately for upload into this repository. The release includes these directories:

- `manuscript_source/` — REVTeX main manuscript, appendices and bibliography
- `paper/` — manuscript PDFs and vector publication figures
- `research/round1/` through `research/round4/` — experiment implementations, protocols, source outputs and checks
- `results/R5_1/` and `src/R5_1/` — latest numerical results and figure/editorial scripts
- `figure_sources/` — figure-ready data and vector source elements
- `provenance/` — figure source indexes and SHA-256 release manifest

**The GitHub landing page is not itself the full research release.** The directory contents above will be available once the accompanying prepared upload bundle has been imported. Verify the release file index and checksums before treating this repository as a complete reproducibility archive.

## Original EEG data

Original EDF recordings are maintained by the [PhysioNet EEG Motor Movement/Imagery Dataset v1.0.0](https://doi.org/10.13026/C28G6P). The prepared research release contains derived analysis arrays and record-level statistics, without mirroring raw EDF files.
