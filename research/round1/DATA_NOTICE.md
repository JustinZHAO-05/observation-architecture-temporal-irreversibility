# Data source and attribution

## Human EEG used in the completed study

**Source:** EEG Motor Movement/Imagery Dataset, version **1.0.0**, contributed
by Gerwin Schalk and colleagues and distributed by PhysioNet.

- Dataset DOI: https://doi.org/10.13026/C28G6P
- Versioned landing page: https://physionet.org/content/eegmmidb/1.0.0/
- Original provider description and run mapping: https://archive.physionet.org/pn4/eegmmidb/
- Database license listed by PhysioNet: **Open Data Commons Attribution License v1.0 (ODC-By 1.0)**.
- License text: https://opendatacommons.org/licenses/by/1-0/

The study uses baseline runs R01 (eyes open) and R02 (eyes closed) for
participants S001-S109: 218 EDF files. The provider describes 64 EEG channels
sampled at 160 Hz, with an additional EDF annotation channel. The original
files and their channel calibration are preserved by the downloader. The
primary analysis uses 12 prespecified channels and the as-distributed reference.

Raw EDF files are obtained directly from the versioned provider path:

```text
https://physionet.org/files/eegmmidb/1.0.0/S{subject:03d}/S{subject:03d}R{run:02d}.edf
```

For example:

https://physionet.org/files/eegmmidb/1.0.0/S011/S011R01.edf

The compact reproducibility package contains derived scores, spectral-cycle
arrays, quality-control tables, and analysis code. It does not duplicate the
raw EDF collection. `src/eeg_study.py --download-only` retrieves missing files
into `data/eegmmidb/`; existing files are reused. Download-status tables are in
`results/download_*.csv`. Independent header checks and selected file hashes
are recorded in `reviews/empirical_audit_exact_outputs.json`.

## Other data and retained exploratory branches

The theory, synthetic network, Gaussian spectral, and finite-record
counterexample outputs are generated by the supplied seeded code. They require
no external experimental dataset.

The initial dataset scout examined additional public C. elegans connectome
files. Those files did not enter the completed EEG or theoretical analyses.
Their individual origins are recorded in `scouts/data.md` and, when included
in the working tree, `data_scout/provenance.json`. They should not be attributed
to EEGMMIDB or treated as an independent empirical validation of this study.
