# R4 科学修订结果

## 核心主线

论文继续围绕同一个问题：观测过程中的时间箭头，能够在什么观测模型及信息条件下归属于潜在动力学？R4将R3剩余的三个数学/计算缺口向前推进：有限阶潜在表示、合法宽频带功率最优、归一化谱形未知时的独立校准。

## 1. 有限阶模型中的精确等价

对严格正定的有限阶谱多项式S，令其R为实偶部分、Y为虚奇部分。Y/sin(omega)本身是有限阶偶多项式。一般构造提供连续偶矩阵V；用Fejér多项式近似V，同时定义P=R+(2cos²omega−1)V、Q=−cosomega V+Y/(2sinomega)。这些定义使HGH*=S在每个近似阶数都严格成立，而足够小的均匀近似误差保留正定性。

因此潜在谱可以是有限阶多项式。利用既有矩阵谱分解定理，它具有因果有限阶移动平均实现。目标维度与动力学复杂度受到具体限制时，一采样观测等价仍然存在。

72个独立生成的目标（维度2/3/6、阶数1/2/3、每格8个）全部通过；最大相对误差1.22e-15，接受的潜在协方差支持4–34。这些阶数表示已找到可行解，不宣称最小。最小连续频率正定性诊断余量为1.35e-5；所有失败候选与加密网格均保留。

## 2. 真正的全频率资源最优

原定理的固定b短延迟发散，与物理路径b(omega)=beta sinomega的有限端点属于不同极限。R4对完整谱g(omega)[I+i beta sinomega J]求总谱迹最优。最优比是g加权的点态最优函数积分。

显式最优谱是有界、实、偶、半正定的，因此对应合法平稳高斯过程。最优矩阵在cosomega=0处可以跳变，而最优数值仍连续。用光滑截断和与严格正定可行谱的凸组合，得到连续正定、精确重构、成本收敛于最优的序列。每个正定近似都能作因果平方可和谱分解。

beta=.8、平谱下最小总谱迹比.854239；AR颜色极点.8时.829345，分别比简单可行表示减少约14.6%和17.1%。该定理针对明确的旋转谱族和固定混合增益，覆盖完整过程，而不是未经检查地拼接各频率的最优值。

## 3. 谱形未知的独立校准

R3已知完整归一化谱形，R4只给定相关性模型类及相对尾界T_L≤tau_L B_*。在独立校准记录上，利用高斯二次型界和三角多项式的全频率控制，得到自洽上界U_B。它的计算只用经验谱和已知尾界，不读取真实B、协方差矩阵、归一化谱形或整体尺度。

600对独立校准/测试记录产生1,680次校准和8,520次分析。不同长度采用同一长记录的前缀，明确为依赖比较。其中360次短校准因分辨条件不满足而弃权；其余1,320个有限上界全部覆盖诊断网格上的真实谱最大值。受模型保证的4,800次测试中，没有证书超越对应总体解析下界，1,680次校准后零假设分析未返回正证书。

b=.9、测试N=32,768时，校准m=65,536得到120/120个正下界；测试N=131,072时，m=16,384即为120/120。b=.65也在较长记录下出现正证书。校准上界/真实谱峰值的中位数随m由4,096增至65,536，从约2.68降至1.20。

长相关AR–MA过程的保证有效，但截至测试N=524,288仍无正证书。这是当前全局界保守性的重要负面结果。错误地把长相关过程当成有限支持过程时，80/80个频谱包络漏掉真实谱；使用正确尾界时80/80覆盖。两个有限样本分支都没有正证书，因此没有把包络失效冒充假阳性计数。

## 4. EEG变换控制

对原始S011R01一段记录，在固定24窗、12通道、57频率估计上应用80个对角频率响应，闭环乘积最大误差1.22e-15。80个实正交旋转保留原始反演散度，相对误差上限7.92e-14，但会改变闭环。实际64通道平均参考作为另一种非可逆投影对照。

这是已知变换的数值管线检验。它使理论与真实观测统计的关系更直接，同时保留71人群体分析的探索性定位。论文没有声称完成了潜在脑动力学的独立生理标定。

## 5. 数学与写作修正

实过程频率对称性改为逐元素复共轭；共轭转置另记为*。补全了谱误差同时控制的实分量计数与范数常数。修正最优矩阵与最优值的连续性区别。白潜在特例被归入标准MA实现基础，核心原创性定位落在固定观测算子的一般表示及所述条件性推断，而不是一般谱分解存在性。

正文和Supplement重复证明已压缩。新增理论证明位于正文Appendices，Supplement保存模型参数、每类负面结果、额外验证及已完成新图。独立数值审计包含20组时域核/滞后谱对照、完整协方差检验、12组70位精度联合极限恒等式、150组新随机矩阵不变性及下界检查。

## 当前结论强度

本版已经完成所报告结果的推导、实验与文稿整合。主要实际限制是长相关条件下的功效，论文将其作为研究结果而非隐藏。没有从有限数据无假设地估计任意协方差尾部，也没有把可逆潜在统计表示认定为脑的真实生理机制。外部同行评审、研究优先性和期刊接受属于投稿阶段的独立判断。
